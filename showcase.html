How to get listed

One entry, one pull request.

The list lives in showcase.json. Add an object for your repo, open a pull request, and it appears here once merged. Stars, language and your avatar are read from GitHub, so there is nothing to keep updated.

It has to be yours

A public repository under your own account. Not a fork, not a course assignment — those belong in the repository index.

Add four fields

repo, title, blurb and a color from the palette: navy, sea, teal, moss, amber, sun, rust, plum. Tags are optional, and so is url — if the project runs somewhere, the card opens the live site.

Open the pull request

A check runs on it — the repo has to exist, be public, be yours, and the colour has to be one of the eight. Broken entries never reach the page.

That is it

Once merged your card is live. Change the blurb any time with another pull request; the counts look after themselves.

Your turn

Put the thing you built where people can find it.

It does not have to be finished or impressive. It has to be yours. Questions? contact@efekurucay.com
