Partition geriye çözme

Yalnızca “solu küçük, sağı büyük” görünümüne bakarak pivotu kesin belirleyemezsin. Adayı orijinal dizide bul, verilen swap algoritmasıyla son diziyi doğrula.

Boşluklar

Aralıklar [start,end); end dahil değil. A/B/C'de k 0-based global index. D'de k 1-based global rank; hedef indeks k−1, recursive call'da k değişmiyor.

Form (a) (b) (c) (d)
A r == k k < r start, r, k r+1, end, k
B end-start == 1 k < r start, r, k r+1, end, k
C end-start > 1 end = r start = r+1 A[start]
D r == k-1 k-1 < r start, r, k r+1, end, k 
def quick_select(A, start, end, k):  # k: global 0-based index
    if end - start == 1:
        return A[start]
    r = partition(A, start, end, end - 1)  # trace için last pivot
    if r == k:
        return A[r]
    if k < r:
        return quick_select(A, start, r, k)
    return quick_select(A, r + 1, end, k)

Part D2 · Merge ile çift sayma

Yöntem

Önce iki yarının kendi içindeki çiftlerini say. Sonra soldan bir x ve sağdan bir y içeren cross çiftleri say. Yarılar sıralıysa uygun y’ler kesintisiz bir prefix veya suffix oluşturur; tek pointer bu sınırı izler.

Konuya dön · Merge ile çift sayma →

Önce Θ(n²) çözümü yaz; sonra sorted half’ları kullanarak lineer combine tasarla.

L ve R sıralı; x > 2y koşulunda j kaç uygun R elemanını gösteriyor. Sonraki x için j?

İpucu
Alt parçaların hangi elemanları kapsadığını ve her çağrının yaptığı işi ayrı yaz. Sınır, indeks ve eşitlik koşullarını küçük bir örnekte dene.
Çözümü ve gerekçeyi göster

1. Brute force

Her i için j=i+1,…,n−1 değerlerini dolaş; formdaki koşul doğruysa sayacı artır. n(n−1)/2 çift kontrolü, Θ(n²) süre.

2. Lineer combine

L ve R artan sıralı; L, orijinal dizinin sol yarısından, R sağ yarısından gelir. Her iki yönde de pointer yalnız ileri gider: toplam O(len(L)+len(R)).

def cross_count(L, R, form):
    j = 0
    count = 0
    for x in L:
        if form == "A":       # x > 2*y
            while j < len(R) and x > 2 * R[j]:
                j += 1
            count += j
        elif form == "C":     # x > y+5
            while j < len(R) and x > R[j] + 5:
                j += 1
            count += j
        elif form == "B":     # y > 3*x
            while j < len(R) and R[j] <= 3 * x:
                j += 1
            count += len(R) - j
        else:                 # D: y > x+10
            while j < len(R) and R[j] <= x + 10:
                j += 1
            count += len(R) - j
    return count

A/C'de uygun y'ler R'nin prefix'i; B/D'de suffix'i. j'yi her x için sıfırlama. Strict > eşitlikte saymaz; B/D'de bu yüzden atlanacakların koşulu <=. Sabit form için branch kontrolü O(1).

3. Divide and conquer

def count_pairs(A, form):
    if len(A) <= 1:
        return A[:], 0
    m = len(A) // 2
    L, left_count = count_pairs(A[:m], form)
    R, right_count = count_pairs(A[m:], form)
    cross = cross_count(L, R, form)
    return merge(L, R), left_count + right_count + cross

merge iki sıralı listeyi lineer zamanda birleştiren standart yordamdır. CountDrops/CountJumps/CountFalls/CountRises sırasıyla A/B/C/D formunu kullanır; istenen sonuç dönen çiftin ikinci bileşenidir.

4. Running time

T(n)=T(⌊n/2⌋)+T(⌈n/2⌉)+Θ(n)=Θ(n log n). Slicing, combine ve merge toplam Θ(n) iş; her seviyede Θ(n), Θ(log n) seviye. Canlı ek bellek O(n), çağrı derinliği O(log n).

5. Correctness

Inductive hypothesis: kısa listelerde yordam sıralı listeyi ve doğru sayıyı döndürür. Her i<j çifti tam bir sınıftadır: ikisi sol yarıda, ikisi sağ yarıda veya biri solda biri sağda. İlk iki sınıf induction ile sayılır. Cross sınıfında orijinal i<j koşulu yarı üyeliğinden gelir; yarıyı sıralamak bu üyeliği değiştirmez. Sıralı R'deki uygun prefix/suffix her x için tam olarak bir kez sayılır. Sınıflar ayrık ve tüm çiftleri kapsar; merge de sıralı listeyi verir. Dizinin tamamını başta sıralamak i<j bilgisini yok eder.

Kontrol örnekleri: A [5,9,2,8,3,1] → 8; B [4,1,13,2,9,20] → 7; C [12,3,15,9,1,7] → 6; D [5,18,2,14,30,11] → 6. PDF'lerdeki cross örnekleri sırasıyla 3,3,4,4 verir.

Yeni girdiyle çift sayma

Önce i<j çiftlerini kâğıtta say. Eşitlikte sayılmayan çiftlere dikkat et. Sonra iki-pointer sonucuyla karşılaştır.

2–16 farklı pozitif tam sayı; her biri en çok 1.000.000.

    return A[0]

return Contains(A[:n//2], x) or Contains(A[n//2:], x)

Inductive step: n≥2 için iki yarı daha kısadır ve birlikte A'nın tamamını, hiç eleman atlamadan kapsar. Hypothesis ile her recursive sonuç x'in o yarıda bulunmasına denktir. x birleşimde ancak ve ancak en az bir yarıda bulunduğundan OR doğru sonucu verir.

Part E · Form D · CountBig: orta eleman iki kez sayılıyor

Yöntem

İki yarının sayılarını toplamak için parçalar ayrık olmalıdır. Ortak eleman iki kez sayılabilir. Python slice yeni liste kopyalar; eleman sayısı n olan iki yarıyı oluşturmak toplam Θ(n) iş ister.

Çözümü ve gerekçeyi göster

CountBig([6,9,2],5) 3 döndürür; 9 iki yarıda da bulunur. Tek uzunluklu herhangi bir alt çağrıda ortak orta eleman x'ten büyükse fazladan sayılır. Başlangıç uzunluğu çift olsa da alt çağrılar tek olabilir (n=6 → 3+3). Kod yalnız fazla sayabilir; böyle bir ortak uygun eleman yoksa sonuç doğrudur.

return CountBig(A[:n//2], x) + CountBig(A[n//2:], x)

Inductive step: n≥2 için iki yarı boş değildir, daha kısadır ve ayrık birleşimleri A'dır. Hypothesis her yarıda x'ten büyüklerin doğru sayısını verir. Ayrık kümelerde sayılar toplandığından yeni satır bütün listedeki doğru sayıyı döndürür.

Slicing: dört form için ortak maliyet

Düzeltilmiş kodların worst case recurrence'ı T(n)=T(⌊n/2⌋)+T(⌈n/2⌉)+Θ(n), sonuç Θ(n log n). Python list slice'ları kopyadır; iki yarının toplam kopyalama maliyeti Θ(n). A/C'de short-circuit bazı çağrıları atlayabilir; bütün dalları gezen girdiler worst case'i gerçekleştirir (A: sıralı liste; C: x listede yok). İndeks aralıklarıyla kopyasız yazılsaydı bu dört algoritmanın worst case'i Θ(n) olurdu; verilen slicing'li kod için bunu yazma.
