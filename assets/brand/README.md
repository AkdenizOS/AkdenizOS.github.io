# AkdenizOS marka kiti

Ön izleme: `index.html`. Toplu indirme: `akdenizos-brand-kit.zip`. Kullanım kılavuzu: `brand-guide.pdf`.

Kanonik işaret `mark.svg`; kelime işaretinin harfleri SVG yollarıdır. Lora 600 kelime işareti, Lora 500 başlıklar ve Manrope arayüz için kullanılır. İsim AkdenizOS yazılır. Sembol çevresinde yüksekliğinin en az dörtte biri kadar boşluk bırakılır.

Profil: 1024 kare. Kapak: 1500×500. LinkedIn kapak: 1584×396. Kare paylaşım: 1080 kare. Hikâye: 1080×1920. Open Graph: 1200×630. Platformların kırpması değişebilir; logolar güvenli orta alanlarda tutulur.

Palmiye geometri kaynağı mark.svg dosyasıdır. Yeni çıktılar aynı kaynaktan üretilir. SVG ölçeklenebilir vektör, PNG raster çıktıdır. Kök dizindeki favicon ve uygulama ikonları mavi zemin üzerinde beyaz palmiyedir. Marka benzersizliği veya tescil doğrulaması yapılmış değildir.
